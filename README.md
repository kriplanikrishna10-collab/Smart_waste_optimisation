# Smart Waste Collection Simulation and Route Optimization System

## Overview
This project simulates waste collection bins and optimizes collection routes using open-source Python technologies. It helps demonstrate how route optimization can reduce the distance travelled by waste collection vehicles.

## Features
- Synthetic waste-bin data generation
- Configurable bin collection thresholds
- SQLite database for storing simulation data
- Route optimization using OR-Tools
- Road network and routing modules
- Streamlit dashboard for visualization
- Automated tests

## Technologies
- Python
- Streamlit
- Pandas and NumPy
- SQLite
- Google OR-Tools
- NetworkX
- Plotly
- Pytest
